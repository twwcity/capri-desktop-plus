# Установка Capri Desktop Plus (Русский)

[ไทย](INSTALL.th.md) · [English](INSTALL.en.md) · [日本語](INSTALL.ja.md) · [한국어](INSTALL.ko.md) · [中文](INSTALL.zh.md) · [Français](INSTALL.fr.md) · [Español](INSTALL.es.md) · [Português](INSTALL.pt.md) · **Русский**

Capri Desktop Plus — форк [Capri Desktop от mochiiwuff](https://github.com/mochiiwuff/capri-desktop). Бесплатно и некоммерчески (продавать запрещено).

## Что нужно

- Windows 10 или 11, 64-бит.
- Около 3 ГБ свободного места (больше, если добавите локальный ИИ или модели картинок).
- Интернет для первой настройки; потом с локальным ИИ всё работает офлайн.
- Работает из любой папки, с внешнего SSD или флешки.

## 1. Скачать

Откройте **[страницу Releases](https://github.com/twwcity/capri-desktop-plus/releases/latest)** и скачайте **оба** файла:

| Файл | Что внутри |
|---|---|
| `Capri-Desktop-Plus-v1.0.1-app.zip` | Приложение, скрипты запуска, распознавание речи (Whisper), инструменты для игр |
| `Capri-Desktop-Plus-v1.0.1-voices.zip` | Её голоса (английский, японский, китайский, корейский, тайский) |

## 2. Распаковать оба в одно место

1. Правый клик на `...-app.zip` → **Извлечь все…** → выберите место (например `D:\` или флешку) → **Извлечь**.
2. То же с `...-voices.zip`, **в то же место**.
3. Получится одна папка `Capri` с `app`, `voice`, `games`, `Start-Capri.vbs` и остальным.

> Не запускайте из zip: сначала распакуйте.

## 3. Запустить Capri

Дважды щёлкните **`Start-Capri.vbs`** в папке `Capri`.

- Если Windows пишет **«Система Windows защитила ваш компьютер»**: **Подробнее** → **Выполнить в любом случае** (приложение не подписано; только в первый раз).
- Через несколько секунд Capri появится внизу экрана.

## 4. Дать ей ИИ

Щёлкните Capri → **Поговорить с ней**. Если ИИ ещё нет, она спросит, какой:

- **На моём ПК (Ollama)** — приватно, офлайн. Capri установит Ollama и скачает модель (gemma3, 3–8 ГБ). Нужно 8 ГБ ОЗУ или больше; на старых ПК медленнее.
- **Онлайн, без аккаунта** — работает сразу (Pollinations). Просто и бесплатно, но глупее.
- **У меня есть ключ** — лучшее качество. Проще всего и бесплатно — **Google Gemini**:
  1. Откройте <https://aistudio.google.com/apikey> и войдите через Google.
  2. **Create API key**, скопируйте.
  3. В Capri выберите **Google Gemini** и вставьте ключ (хранится зашифрованным на вашем ПК).
  4. Нажмите на имя модели вверху чата, чтобы выбрать. `gemini-3.5-flash-lite` — самая быстрая.

ИИ можно сменить в любой момент: нажмите на имя модели вверху чата.

## 5. Язык, голос и микрофон

- **Язык:** правый клик на Capri → **Язык** → ваш. Она также отвечает на языке, на котором вы пишете.
- **Голос:** включён по умолчанию (правый клик → Звук → *Speak her answers aloud*).
- **Микрофон:** кнопка микрофона рядом со строкой ввода. Выбор микрофона: правый клик → **Microphone**. Сигнал звучит в начале и в конце прослушивания.

## 6. Попробуйте

| Напишите в чат | Что произойдёт |
|---|---|
| `play Shape of You on youtube` | Откроет и запустит первое видео |
| `what's playing?` | Скажет, что играет; над чатом появится медиапанель с обложкой, ±10 с, следующий, громкость, повтор и таймер сна |
| Ссылку | Прочитает заголовок и откроет |
| `+` → **Code mode** → `make a snake game` | Напишет игру и откроет её |
| `+` → **PC agent** → `sort my Downloads folder` | Разложит файлы, спросив перед рискованными действиями |
| `+` → **Create image** | Нарисует (нужны модели картинок, см. ниже) |
| Значок телефона вверху чата | Голозвонки персонажам Edgerunners |

Горячие клавиши: **Ctrl+Alt+C** — спрятать/показать. Правый клик на ней — полное меню.

## Дополнительно

### Запуск при подключении диска
Один раз дважды щёлкните `Setup-This-PC.cmd` на каждом ПК. Отменить: `Remove-From-This-PC.cmd`.

### Claude Code или Codex как её мозг
Установите [Claude Code](https://claude.com/claude-code) или [Codex](https://developers.openai.com/codex), один раз войдите в терминале и выберите в меню моделей. Рабочая папка: правый клик → ИИ-модель.

### Картинки
Положите `sd-cli.exe` из [релизов stable-diffusion.cpp](https://github.com/leejet/stable-diffusion.cpp/releases) в `Capri\imagegen\` и модель:
- быстро: `sd_turbo.safetensors` с <https://huggingface.co/stabilityai/sd-turbo> в `Capri\imagegen\`
- лучше (медленно, 8 ГБ+ VRAM): GGUF-файлы Wan 2.2 TI2V 5B в `Capri\imagegen\wan\`

### Лучшие тайские голоса для Omi и D
Не включены (нет лицензии на распространение). С Python 3.10+: `pip install torch transformers onnx huggingface_hub`, затем `python tools/convert-thai-voice.py out VIZINTZOR/MMS-TTS-THAI-FEMALEV2`, и скопируйте `out\model.onnx` и `voice\sherpa\vits-mms-tha\tokens.txt` в `Capri\voice\sherpa\vits-mms-tha-female\` (MALEV2 → `vits-mms-tha-male` для D).

### Minecraft: мод Capri Link
1. Minecraft Java Edition **1.21.1**.
2. Запустите официальный [установщик Fabric](https://fabricmc.net/use/installer/) → Client → Minecraft **1.21.1** → Install.
3. Лаунчер Minecraft → **Установки** → **Новая установка**:
   - Версия: `fabric-loader-…-1.21.1`
   - Папка игры: `…\Capri\games\minecraft\capri-1.21.1`
4. Один раз запустите Capri (она скопирует мод в эту папку), затем играйте с этой установкой.
5. В чате игры: `capri help`, `capri scan`, `capri scan diamond`, `capri shock`, `capri shock all` или `capri <вопрос>`. Из чата на рабочем столе тоже: «find diamonds».

> Используйте официальный установщик Fabric, а не версию из другого лаунчера: она может падать с «Unable to prepare assets for download».

## Проблемы

| Проблема | Решение |
|---|---|
| Не отвечает или очень долго | Нажмите на имя модели в чате и выберите другую (облачные модели бывают перегружены). С Ollama первый ответ после запуска может занять минуты. |
| Нет голоса | Проверьте, что архив голосов распакован в ту же папку `Capri` (должна быть `Capri\voice\sherpa\kokoro-multi-lang-v1_0`). |
| Микрофон не слышит | Правый клик → Microphone → нужный. |
| «That model isn't available» | Старые модели Gemini закрыты для новых ключей: выберите `gemini-3.x`. |
| Windows блокирует | Подробнее → Выполнить в любом случае, или правый клик на zip → Свойства → **Разблокировать** перед распаковкой. |

## Удаление

Закройте Capri (правый клик → Выход) и удалите папку `Capri`. Если использовали `Setup-This-PC.cmd`, сначала запустите `Remove-From-This-PC.cmd`.
